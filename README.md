# Ludo Дөрвөн Өнгө

4 хүртэл хүн өөр өөрийн утаснаас код эсвэл холбоосоор холбогдож тоглодог Ludo. Хүн дутвал бот нөхнө. Өөр сервер, суулгалт шаардахгүй, нэг `index.html` файл.

## Тоглох
1. "Шинэ өрөө үүсгэх" дарж 4 оронтой код авна.
2. Найзууд кодыг "Орох" дээр оруулна, эсвэл "Хуваалцах" холбоосоор орно.
3. Хост "Тоглоом эхлүүлэх" дарна. "2v2 баг" горимд хамтрагчийн хөлийг ч нүүлгэж болно.

## Дүрэм
- 6 буувал хөл гарна, 6 буувал дахин шидэнэ. Хөл идвэл дахин шидэнэ, гэртээ орсон хөл ч мөн адил.
- Од болон өнгөт эхлэх нүдэнд хөл идэгдэхгүй.
- Самбар дээр төрөл бүр 2-2 тэмдэг гарна. Хөлөөрөө буувал авна: Нүүдэл сонгох (1-6), Бүрэн бамбай (нэг тойрог), Нэмэлт шоо. Ногоон +1 нүдэнд зогсвол шууд дахин шидэнэ.
- Нэг ээлжид 10 секунд. Хугацаа хэтэрвэл автоматаар шидэж, нүүнэ.

## GitHub Pages
Settings → Pages → Source: `main` branch, `/ (root)`. Хэдэн минутын дараа `https://<таны-нэр>.github.io/<repo>/` дээр нээгдэнэ.

## Техникийн тэмдэглэл
Олон тоглогч нь [PeerJS](https://peerjs.com) (WebRTC) ашигладаг. Хост нь өрөө болж, найзууд түүнтэй шууд холбогдоно. Хост хуудсаа хаавал тоглоом дуусна. Зарим мобайл сүлжээнд WebRTC холбогдохгүй байж болно.
